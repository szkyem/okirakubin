お気楽便 会員向け使い方マニュアル

商品登録から保管商品、発送依頼、請求書ダウンロードまでの基本操作をまとめたマニュアルです。

1. トップ画面

ログイン後、最初に表示される画面です。現在の商品状況と、最近のお知らせを確認できます。

2. 商品登録

新しく検品や撮影を依頼する商品を登録します。

必須項目

  • 商品名
  • ナンバリング
  • 作業依頼
  • ボディの本数
  • レンズの本数
  • 検品確認が必要な周辺機器本数

任意項目

  • 購入先URL
  • 動画撮影
  • Thanksカード同梱
  • お気楽便Thanksカード・チラシ同梱
  • オプションコメント

登録は「登録する」ボタンを押したときだけ実行されます。必要項目が未入力の場合は登録できません。
※検品確認が必要な周辺機器本数は必須項目です。該当がない場合は0を入力してください。
※お気楽便Thanksカード・チラシ同梱を不要にする場合は、別途100円かかります。
※ストロボ、バッテリーグリップなど、動作確認等の検品が必要な付属品は、1点ごとに追加検品料金が発生します。

3. 保管商品

商品登録を済ませた商品の一覧は、保管商品欄で確認できます。登録済み商品はまだ検品が済んでいない商品で、検品が済むと保管商品の項目へ移動します。

主な操作

  • 商品名・ナンバリングで検索
  • 商品情報の詳細確認
  • 料金の詳細確認
  • 検品結果のGSS出力
  • 国内発送、海外発送、返品依頼、送料会員事前負担で国内発送の依頼

検品結果は、情報の「詳細」を押すと中身を確認できます。

発送する場合は、一番左の発送欄にチェックを入れると、国内発送、海外発送、返品依頼などの選択肢が表示されます。内容に応じて選択してください。

※送料会員事前支払で国内発送する場合は、QRコード等が必要になる場合があります。その場合、Discordへの通知を行うため、利用する前に管理者へご連絡をお願いします。

GSS出力

「出力」ボタンを押すと、設定済みのGoogleスプレッドシートに検品結果を出力します。

GSSの出力先は、画面右上の「設定変更」から設定します。GoogleスプレッドシートのURLとシート名を入力してください。

列 出力内容
A出力日
B商品名
Cナンバリング
D検品日
E確認結果
F写真URL
4. 発送元登録

発送依頼で使用する発送元情報を登録します。ご自身の自宅や倉庫などを登録できます。

入力項目

  • 発送元名
  • 郵便番号
  • 都道府県
  • 住所
  • アパート名、会社名など
  • お名前
  • 電話番号

発送依頼時に発送元を選択できるようになります。

5. 請求書ダウンロード

管理者が発行した請求書を月ごとにダウンロードできます。

表示内容

  • 発行済みの月はCSV・PDFボタンが表示されます
  • 未発行の月は「未発行」と表示されます
  • 必要に応じてCSVまたはPDFをダウンロードできます

請求書は管理者が発行した後に表示されます。未発行の月はダウンロードできません。

6. 基本情報

営業時間、発送、検品、連絡手段などの基本情報を確認できます。

トップには直近のお知らせが表示されます。過去のお知らせや基本ルールは基本情報から確認します。

7. 基本の流れ

利用の基本フロー

  1. 商品登録で依頼内容を登録する
  2. 管理者側で検品・撮影が行われる
  3. 保管商品に移動した商品情報を確認する
  4. 必要に応じてGSSへ検品結果を出力する
  5. 発送が必要な商品を選択して発送依頼する
  6. 発送済みになった商品は発送管理で確認する
  7. 発行済みの請求書を請求書DLから確認する
8. GSS出力と商品文生成

検品結果をGoogleスプレッドシートへ出力する

保管商品の「出力」ボタンを押すと、検品結果を設定済みのGoogleスプレッドシートへ出力できます。

OpenAI APIキーを設定すると、出力された検品結果をもとに、自分の出品スタイルに合わせた商品文生成も自動で行えます。商品文生成を使わない場合は、商品文生成通知URLやOpenAI APIキーの設定は不要です。

出力先は、画面右上の「設定変更」から設定します。

出力される内容

列 内容
A出力日
B商品名
Cナンバリング
D検品日
E確認結果
F写真URL
G商品文の生成結果（OpenAIの自動生成が設定されている場合のみ出力対象）

G列の生成結果が空欄の場合、商品文生成の対象になります。すでにG列に文字が入っている場合は、重複生成を防ぐため自動生成されません。

第1段階：検品結果をGSSへ出力する

お気楽便の検品結果のみをGoogleスプレッドシートへ出力する設定です。商品文生成を使わない場合は、この第1段階だけ設定してください。

設定方法

  1. 以下のテンプレートを開き、コピーを作成します。
    お気楽便 GSS出力テンプレート
  2. コピーしたGoogleスプレッドシートの共有設定を開き、mail@okirakubin.com を「編集者」として共有します。
  3. 会員ページ右上の「設定変更」を押します。
  4. 「GoogleスプレッドシートURL」に、コピーしたGSSのURLを入力します。
  5. 「シート名」に、ご自身の実際のシート名を入力します。
  6. 「保存する」を押します。

第1段階のみ利用する場合は、「商品文生成通知URL」は設定しないでください。

第2段階：OpenAI APIキーを設定して商品文を自動生成する

商品文生成を使う場合は、Googleスプレッドシート側のApps ScriptにOpenAI APIキーを設定します。これにより、検品結果や商品文生成設定シートの内容をもとに、G列へ商品文が自動で出力されます。

OpenAI APIを利用する場合は、OpenAI Platformへのログインまたは会員登録が必要です。新規登録の場合、利用開始前に少額の初回チャージが必要になる場合があります。料金はOpenAI側の設定・利用量・為替により変わります。

現在案内している商品文生成用スクリプトは、低コストで使いやすいモデル設定を想定しています。目安として、商品文1件あたり数十銭程度、100件生成しても数十円程度に収まることが多い想定です。ただし、参考文が長い場合や生成文字数が多い場合は金額が増えます。必要に応じて、GSS側Apps Scriptのモデル設定を変更できます。

商品文生成設定シートには、GSS内に記載している参考例に基づいて、参考タイトル、参考文、出品ルール、書き方の指示、禁止事項、必ず入れる文言を設定してください。

OpenAI APIキーの準備

  1. OpenAI Platformにログインします。アカウントがない場合は会員登録を行います。
  2. 必要に応じて、OpenAI Platformで支払い設定または初回チャージを行います。
  3. APIキー作成画面から新しいAPIキーを作成します。
  4. 作成したAPIキーを控えます。APIキーは再表示できない場合があるため、取り扱いに注意してください。

GSS側Apps Scriptへの設定

  1. コピーしたGoogleスプレッドシートを開きます。
  2. 画面上部の「拡張機能」から「Apps Script」を開きます。
  3. テンプレートには商品文生成用スクリプトが入っているため、基本的に新しく貼り付ける必要はありません。
  4. 左側メニューの「プロジェクトの設定」を開き、「スクリプト プロパティ」を表示します。
  5. スクリプトプロパティに、キー名「OPENAI_API_KEY」、値に作成したOpenAI APIキーを設定します。
  6. 保存後、Apps Script画面上部の実行関数から「setupOkirakubinDescriptionGenerator」を選び、1回実行します。
  7. 初回実行時にGoogleの確認画面が出た場合は、内容を確認して許可します。

Webアプリとして公開する方法

  1. Apps Script画面右上の「デプロイ」を押します。
  2. 「新しいデプロイ」を押します。
  3. 種類の選択で「ウェブアプリ」を選びます。
  4. 説明欄には「お気楽便 商品文生成」など、分かりやすい名前を入力します。
  5. 実行するユーザーは「自分」を選びます。
  6. アクセスできるユーザーは「全員」を選びます。
  7. 「デプロイ」を押します。
  8. 初回の場合は、Googleの確認画面で許可を行います。
  9. 表示されたWebアプリURLをコピーします。
  10. 会員ページ右上の「設定変更」を開き、「商品文生成通知URL」に貼り付けて保存します。
